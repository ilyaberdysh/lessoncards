# Lesson Cards

Приложение для Mac, которое превращает урок английского в карточки.

- Сайт: https://ilyaberdysh.github.io/lessoncards/
- Скачать: [Releases](https://github.com/ilyaberdysh/lessoncards/releases/latest)

Требуется Mac с Apple Silicon и macOS 14.4 или новее.

В этом репозитории нет исходного кода приложения. Здесь лежат сайт для GitHub Pages и публичные релизы.
